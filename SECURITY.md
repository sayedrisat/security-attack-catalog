# Security policy

This policy covers vulnerabilities in the Security Attack Catalog's code, dependencies, GitHub Pages site, and contribution workflow. It does not cover vulnerabilities in third-party products described by catalog entries.

## Supported version

The current `main` branch and the live GitHub Pages deployment receive security fixes. Older copies are not maintained.

## Report a vulnerability privately

Use GitHub's **Report a vulnerability** button on the repository's [Security Advisories page](https://github.com/sayedrisat/security-attack-catalog/security/advisories). Private vulnerability reporting is enabled for this repository. Include the affected URL or file, impact, and safe reproduction details. Do not include real credentials, private user data, or a public proof of concept before a fix is available.

For inaccurate attack descriptions or prevention advice, open a [public correction request](https://github.com/sayedrisat/security-attack-catalog/issues/new?template=correction.yml) instead.
