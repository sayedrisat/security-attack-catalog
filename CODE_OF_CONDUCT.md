# Code of Conduct

This project welcomes people who want to make security knowledge clearer and more accurate.

## Expected behavior

- Discuss evidence and technical claims respectfully.
- Give constructive feedback on contributions, including when a proposed entry is inaccurate or overlaps another.
- Respect different experience levels and avoid personal attacks, harassment, or discriminatory language.
- Do not post private data, credentials, or instructions targeting systems without authorization.

## Enforcement

The maintainer may edit or remove comments, close discussions, or block participants when these expectations are not met. For a concern that can be discussed publicly, open an issue and describe the behavior without sharing personal details. For abuse or harassment that should not be posted publicly, use GitHub's **Report content** control or contact the maintainer through the public profile linked in the README.

This code applies to repository issues, pull requests, discussions, and other project spaces.
